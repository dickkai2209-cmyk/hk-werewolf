# HK狼人殺 · 香港網殺

純前端、單檔、可離線運行嘅香港面殺法官工具。風格參考暗黑哥特維多利亞塔羅卡牌風，首屏對齊參考圖。

## 點樣開啟

- **電腦**：用瀏覽器直接打開（雙擊）`index.html` 即可，無需安裝、無需網絡、無需伺服器。畫面固定 9:16 手機框，較高螢幕會在框外留深色邊。
- **手機**：把 `index.html` 同 `cards/` 資料夾一齊傳到手機，用 Safari／Chrome 開啟；或以本機靜態伺服器開啟。請用豎版。
- 所有資料存於瀏覽器 `localStorage`（前綴 `hk-werewolf-`），重新整理可恢復進度。左上頭像同名字存在 `hk-werewolf-profile`。

## 用法摘要

1. 預設進入「板子」大廳（與參考圖同一幅 9:16 畫面）。左上角係你自己嘅頭像同名字，撳入去可以改（「我的」頁都可以改）。新手／娛樂／進階三張場次卡會顯示官方卡冊頭像（預言家、守衛、白狼王）。左邊香港夜景有少少燈光同雲霧動畫（系統若開啟「減少動態效果」則只顯示靜態圖）。
2. 其他分頁（角色、好友、我的、開房、跟房、板子管理）用同一套繪製頂欄同底欄，底欄金色高亮會跟住分頁郁。法官口令小抄改喺「我的」或大廳「查看」介紹入面打開。
3. 開房：選板子同 6–12 人，生成 4 位房號，進入法官控制台。可隨機或手動派牌，並用「傳閱看牌」翻牌給玩家看完再蓋上。
4. 夜晚引擎會按角色順序出示廣東話法官口令，並自動結算「同守同救奶穿」、藥劑禁用、獵人開槍狀態，天亮自動播報。
5. 白天支援警上（上警、退水、警徽流、撕徽／移交）、放逐投票、平票 PK、狼人自爆（雙爆吞警徽），以及一鍵複製復盤戰報。
6. 「角色（色）」睇塔羅圖鑑；「好友」管理常客同勝率；「我的」改頭像名字、睇場次統計、匯出／匯入 JSON 備份。

## 官方卡冊

解壓後請保持 `index.html` 同 `cards/` 資料夾喺同一層。`cards/wk-0.webp` 係牌背，`wk-1.webp` 至 `wk-167.webp` 係官方角色卡（1 狼人、2 平民、3 預言家……）。角色圖鑑會顯示全部 167 張；已內建技能嘅常用角色可以翻牌睇說明，其餘只顯示官方卡面，唔會杜撰技能。

只用單一 `index.html`（冇 cards 資料夾）仍然可以開房同做法官流程，卡面會退回內建繪圖。

若要覆蓋某張常用角色卡，改 `ROLES_CONFIG` 裡面該角色嘅 `avatarUrl` 即可。新增角色請喺 `ROLES_CONFIG` 加一項，填 `id`、`name`、`camp`（`wolf` / `god` / `villager` / `third`）、`nightOrder`、`avatarUrl`、`customSkillDesc`。未有官方技能文本就唔好亂填。

## 備份

「我的」頁可匯出／匯入 JSON（含自訂板子、好友、房間、精分道具、復盤，以及頭像同名字）。匯入前會要求確認覆蓋。建議定期備份，以免清除瀏覽器快取後遺失資料。
